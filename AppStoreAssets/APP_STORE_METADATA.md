## Description

Tidyset is a private data-cleaning workspace for turning inconsistent CSV, TSV, Excel, and JSON files into dependable datasets. It combines approachable suggested fixes with professional transformation tools—and runs locally on your device.

START WITH REVIEWABLE SUGGESTIONS

Tidyset examines the loaded table and proposes deterministic fixes for common problems such as stray whitespace, inconsistent capitalization, near-duplicate labels, and missing values. Review each suggestion, apply only what you want, and see the result directly in the table.

CLEAN AND TRANSFORM

• Trim, normalize case, and standardize text
• Find and replace with plain text or regular expressions
• Fill missing values with practical strategies
• Split and extract values into useful structures
• Filter rows and reshape working data
• Change column names and types
• Build formulas for derived values
• Cluster similar values and resolve inconsistent categories
• Detect and handle duplicate records

REUSABLE, AUDITABLE RECIPES

Every cleaning action becomes a visible, reversible recipe step. Save a recipe and apply the same process to next week’s export, next month’s report, or another file with the same structure. This makes repeat work faster and decisions easier to explain.

FOR EVERYDAY USERS

Fix contact lists, survey exports, inventories, event registrations, personal budgets, and spreadsheets assembled from multiple sources. Tidyset helps you get a clean result without learning a programming language.

FOR PROFESSIONALS

Prepare imports, standardize reporting extracts, reconcile inconsistent categories, create repeatable QA steps, and document transformations for colleagues or clients. Tidyset is useful for analysts, operations teams, researchers, consultants, marketers, finance teams, and developers.

PRIVATE BY DESIGN

Your datasets and recipes stay on your device. Tidyset does not upload file contents, require a cloud account, or collect analytics. Open a file, clean it locally, and export the result to a location you choose.

SUBSCRIPTION

Start with a one-week free trial. After the trial, an active monthly or annual Tidyset Pro subscription is required. The subscription unlocks the complete app on iPhone, iPad, and Mac and supports ongoing format, transformation, compatibility, and platform updates. The subscription renews automatically unless cancelled in App Store settings.
